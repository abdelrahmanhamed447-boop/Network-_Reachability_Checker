# Network_Reachability_Checker

## Project Overview
A Python-based network reachability checker that simulates OSPF path calculation using Dijkstra's algorithm to find the lowest-cost path between routers.

## How It Works
The project represents the network as a weighted graph, where routers are nodes and network links are represented by costs. Dijkstra's algorithm is used to calculate the lowest-cost path between a source router and a destination router.

## Technologies Used
- Python
- Dijkstra's Algorithm
- OSPF Concepts
- Priority Queue (`heapq`)

## Example
The project calculates the lowest-cost path from `Router_A` to `Router_D` based on the configured network topology.
