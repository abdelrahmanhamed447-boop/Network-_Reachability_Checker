### 🔹 Network Reachability Checker

**Python | Dijkstra's Algorithm | OSPF Concepts | Network Automation**

* Developed a Python-based network reachability checker that simulates **OSPF path calculation** using **Dijkstra's Algorithm**.
* Represented the network topology as a **weighted graph**, with routers as nodes and network links represented by configurable costs.
* Implemented Dijkstra's algorithm to calculate the **lowest-cost path** between source and destination routers.
* Used Python's **`heapq` priority queue** for graph-based path calculation.
* Demonstrated network routing concepts, shortest-path calculation, and basic network automation.
* Example scenario: calculated the lowest-cost path from **Router_A → Router_D** based on the configured topology and link costs.
